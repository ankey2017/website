## 修复：蓝色 Hero 区副标题看不清（两个产品页）
- 根因：CSS 里 `p { color:#374151 }` 写在 `header { color:#fff }` 之后，两者优先级相同（0,0,1），后者被覆盖 → Hero 的 `<p class="sub">` 变成深灰字压深蓝底。
- 修复：给 `header .sub` 显式加 `color:#ffffff` + `font-weight:500` + 轻微 `text-shadow`，并去掉 `opacity:.95`。
- 已同步修复 `products/qidantong/index.html` 与 `products/saleSystem/index.html`。
- **项目约定**：不要再依赖父级 `color` 让子级 `p` 继承白色文字，白字区块一律在具体选择器上显式声明颜色。
