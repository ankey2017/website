## 页头去渐变 + 与产品页高度严格对齐

- 用户要求：去掉页头渐变过渡色；蓝色页头高度与 `products/qidantong/index.html` 完全一致。
- 做法：
  - 删除 `header::before`（点阵纹理）与 `header::after`（底部渐隐到 #f8fafc 的过渡层），背景改为纯色 `#2563eb`；nav 改为纯色 `#1e40af`（原来半透明毛玻璃）。
  - 页头结构回退成与产品页相同的节奏：`badge-top`(上) → LOGO → `sub`(18px，带 `<br>` 固定 2 行) → `kv`(纯文字 ✓) → `hero-cta`(32px)。padding 56/16/64，移动端 40/16/44。
  - **关键换算**：产品页 h1 为 36px / line-height 1.35 → 行盒 48.6px、下边距 14px。LOGO 高度取 48.6px（移动端 35.1px = 26×1.35）、margin-bottom 14px，因此页头总高与产品页逐像素相同。
  - nav 用 flex 居中 + `min-height:52px`；原因是产品页 inline 链接受 nav 自身 16px 字号的 strut 影响恒为 52px，flex 布局下会掉到 50.25px，加 min-height 才对得上。
- **实测验证**（Chrome `--headless=new --dump-dom` 注入脚本读 getBoundingClientRect，1280 与 390 两个宽度）：
  - 1280：两页 header 456.34 / nav 52；
  - 390：两页 header 519.72 / nav 52。
  - 探针脚本（生成 `__probe_*.html` 副本、测完即删）用完已清理，未留在仓库。
- 复用方法：本机 Chrome 在 `C:\Program Files\Google\Chrome\Application\chrome.exe`，可用 `--headless=new --window-size=W,900 --virtual-time-budget=4000 --dump-dom file:///...` 注入脚本读取元素尺寸，用于跨页面版式对齐校验。
