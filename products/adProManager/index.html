功能详解：跟着一单生意走一遍

下面都是软件里的真实界面（数据为演示数据）。客户建档 → 订单立项 → 录料核算 → 制作安装 → 收款开票 → 对账催款，就是完整的一单。

客户建档→ 订单立项→ 录 BOM 算成本毛利→ 制作安装→ 收款 / 开票→ 回款对账→ 收支工资 · 月利润

1. 工作台：打开软件先看六个数

登录后第一屏就是工作台。今日订单、待回款总额、未开票订单、本月总收入、本月总支出、本月纯利润，六个卡片摆在一起，生意状况一眼看完。下面的快捷入口可以直接新建订单、新增客户、新增支出、录物料、登记收款。

工作台：六个核心指标 + 快捷入口，右上角显示授权状态
  • 待回款看板：外面还有多少钱没回来，是每天最该关心的一个数，直接放在首页。
  • 未开票订单单独统计：该开票没开的单子不会漏掉，月底不用翻账找。
  • 授权状态常驻右上角：试用期显示剩余订单名额，正式版显示"已永久激活"。

2. 客户管理：客户的账都在他自己名下

客户名称、联系人、电话、地址、客户分类（零售 / 工程 / 长期合作）、信用额度、身份证附件、备注，一次录清楚。列表直接带出总应收、已收款、未收款三个数——谁欠、欠多少，不用另开一张表算。

客户管理：总应收、已收款、未收款跟着客户一起显示
  • 点开就是台账：客户行点进去，这个客户的全部订单、历史回款、总欠款一屏看完。
  • 信用额度：长期合作的老客户可以设一个额度，赊到什么程度心里有数。
  • 附件留档：营业执照、身份证这类材料直接传上去，下次要用不用再让人发一遍。
  • 导入导出 Excel：老客户名单可以一次性导进来，客户资料也能导出去备份。

3. 订单与项目：一单从立项到结清都在这里

订单是整个系统的中心。订单编号、下单日期、客户、项目名称、工程类型（广告牌 / 发光字 / 门头等）、尺寸、工艺、报价总金额、设计师、安装人员，一张单把这些都记全。收款状态固定四档，进度推进改一下状态就行，不用自己写备注。

订单管理：按客户、工程类型、收款状态筛选
订单详情：基础信息 + 物料清单 + 收款状态与开票
  • 四档回款状态：未结款 / 部分回款 / 已开票未回款 / 已结清，谁欠、欠在哪一步一目了然。
  • 工程类型分开记：广告牌、发光字、门头各是一类，做统计或者回看同类工程的报价，有参照。
  • 开票记录与订单附件：开没开票、图纸合同传在单子上，出问题翻单子就有依据。

4. 物料与 BOM：这单到底用了多少钱的料专业版

订单里可以直接录物料清单：物料名称、规格、数量、单价，小计自动算，整单材料总成本自动汇总，报价减掉材料成本就是这单的毛利。物料本身先在物料基础库里建好档，录单时下拉选一下，单价自动带出来。

物料基础库：分类、规格、单位、采购单价与历史进价
  • 常用料先建档：钢材、铝板、亚克力、LED 灯、油漆、五金配件，按你的习惯分类。
  • 历史进价留底：同一种料以前什么价买的一直存着，涨价了能看出来，报价不会还按老价算。
  • 毛利实时可见：边录料边看毛利，报价压得太低当场就能发现，不用等做完再后悔。
  • 标准版不开放这一块：只做订单和回款的话，订单页会隐藏物料区，界面更干净。

5. 回款对账：欠的钱要看得见、催得动

收款以收款单的形式登记，绑定到具体订单，记金额、日期、付款方式（微信 / 支付宝 / 对公 / 现金）。欠款台账可以把没结清、已开票未回款的分开筛出来，还能设到期前 N 天提醒。

回款对账：按客户、订单、收款状态筛选欠款明细
  • 到期提醒：快到约定回款日的时候提醒你，别等客户"忘了"才想起来催。
  • 一键导出对账单：把某个客户的全部欠款导成 Excel 发过去，发货时间、金额、已付多少全在表上，对账不吵架。
  • 已开票未回款单独一档：票开了钱没到，这部分最容易变成烂账，系统单独列出来盯。

6. 收支与工资：月底利润不用自己拿计算器算

收入这边，订单收款自动同步成营业收入，零星收入也能另记；支出分两类——物料采购归到项目成本，房租水电运杂费外协加工算日常开销。工资单独一个页签，基本工资、提成、扣款、实发工资录进去，自动计入当月成本。

收支管理：营业收入、费用支出、工资支出三个页签
工资支出：基本工资、提成、扣款、实发一目了然
  • 收入自动来：订单那边登记收款，收支表里就有营业收入，不用录两遍。
  • 支出能挂订单：这笔钱是给哪个工程花的，挂上去，单项目成本就能单独算。
  • 工资进成本：工资不只是发钱记录，它也是月度成本的一部分，利润才算得准。

7. 系统设置与操作日志：数据归你自己管

系统设置里管员工账号和权限、数据库备份与恢复、Excel 导出模板，软件激活也在这里。操作日志是独立菜单，登录、新增、修改、删除、导出、激活这些动作都会记下来，谁在什么时候动了什么，查得到。日志只留最近三个月，过期自动清理，不会把硬盘塞满。

系统设置：账号权限、备份恢复、导出模板、软件激活
操作日志专业版：按时间、类型、操作人筛选
  • 一键备份：数据库拷到自己选的目录，丢到U盘或另一台电脑就行，建议每周来一次。
  • 多账号分权专业版：管理员加多个普通账号，业务员录客户开单，但设置和日志进不去。

常见问题

Q：客户资料、报价、欠款这些数据会上传吗？

A：不会。所有数据保存在电脑本地的 SQLite 数据库文件里，软件不联网也能完整使用，不需要注册云端账号，也没有同步服务器。

Q：标准版和专业版是两个安装包吗？以后想升级怎么办？

A：同一个安装包，差别只在授权串里的版本标识。先买标准版，日后补差价换成专业版授权串，粘进去就解锁物料库、BOM、多账号和操作日志，原有数据一条不用重录。

Q：试用版有什么限制？

A：只限制可录入的订单数量，剩余名额在界面右上角一直显示。客户、订单、回款、收支功能都可以正常试用，达到上限后禁用新建订单，激活后解除。

Q：BOM 里的材料价，是采购价还是报价？

A：算成本用的是采购单价，也就是你实际进料的钱。毛利＝订单报价总金额 − 材料总成本，所以看到的是这单的毛利润，不含人工和杂费——那些记在收支里的工资和日常费用中，月底一起算净利。

Q：一单分三次收款，能记清楚吗？

A：可以。每笔收款都是一张收款单，绑到同一张订单上，金额、日期、付款方式（微信 / 支付宝 / 对公 / 现金）分别记。订单状态会跟着走：未结款 → 部分回款 → 已结清。

Q：能给员工开账号吗？会不会把账改乱？

A：专业版支持管理员加多个普通账号（标准版只有单管理员）。普通账号看不到系统设置和操作日志，所有动作都会留痕，谁改了什么查得到。

Q：数据怎么备份？电脑坏了会不会全丢？

A：系统设置里有备份功能，把数据库备份到你指定的目录，复制到U盘或另一台电脑即可，恢复时导入回来。建议每周备份一次。

Q：换电脑了怎么办？

A：授权串绑定本机机器码，换电脑需要重新申请。具体规则和迁移方式请参考统一售后页面。

Q：我完全不懂电脑，能学会吗？

A：界面是左侧菜单加右侧表格的常见管理软件样式，录单顺序跟做生意一样：选客户、填项目、录料、存单。常用的就四五个页面，正常半小时内可以上手。

Q：装不上 / 杀毒软件报毒怎么办？

A：单机小工具可能被部分杀软误报，可先加入信任列表再运行。遇到无法解决的问题，请通过售后页面联系处理。
