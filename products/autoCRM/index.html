客户不是没来，是没人跟到底

留了电话没存、说好下周回访忘了、试驾完就没了下文——4S 店里最贵的成本，是那些再也没联系上的意向客户。

客销管家把「线索 — 跟进 — 到店 — 试驾 — 成交 — 战败」这条链路装进一台电脑。每个客户只有一个档案、一条状态、一条完整的沟通时间线：谁跟的、聊了什么、约了什么时候再来、最后成没成，全在里头。到期该回访的客户，首页自动列出来。

功能详解：跟着一条线索走一遍

下面都是软件里的真实界面（数据为演示数据）。客户进店登记 → 电话/微信跟进 → 约到店 → 试驾 → 成交或战败，就是完整的一条链路。

新线索→ 跟进中→ 邀约到店→ 试驾→ 已成交 任意环节都可登记 战败（价格偏高 / 选择他店 / 暂不购车 / 家人反对），战败客户单独留存，管理员可"恢复为线索"重新激活。

1. 首页看板：今天要跟谁，一眼就知

登录后默认进首页。四张指标卡回答"这个月卖得怎么样"：今日新增线索、待回访客户、本月成交订单、本月成交金额。两张清单回答"今天要做什么"：待回访客户、近期动态。右上角三个快捷入口——新增客户、登记试驾、录入成交，直接开工。

首页看板：四张指标卡 + 待回访清单 + 近期动态 + 快捷入口
  • 待回访清单会冒红：到期和逾期的客户排在最前面，逾期的还会标出已经拖了几天。
  • 数据按账号范围算：销售只看自己的，主管和管理员看全店，同一个界面不同口径。
  • 近期动态倒序六条：谁刚跟进、谁刚试驾、谁刚成交，团队的节奏看得见。

2. 客户线索：进店就登记，别让它变成一张纸条

客户编号自动生成（KH-年份-序号），姓名、手机号、意向车型、预算区间、意向颜色、线索来源、归属销售、备注、附件一次录清。手机号是查重键——同一个人录第二次会直接提示已有档案，并给一个跳转入口，不会出现一个客户三条记录。

客户线索：关键词、车型、来源、状态、归属销售组合筛选
新增客户：分组表单，必填项没填按钮置灰
  • 来源分得细：到店、抖音、电话、转介绍、外拓、其他，半年后回看哪种渠道最出单，有依据。
  • 手机号查重：录重了当场提示"该手机号已存在客户档案（编号 KH-2026-0031）"，点一下就跳过去。
  • 附件能传：报价单、微信截图、证件照都挂在客户档案上，换人接手不用再问一遍。
  • 回车即查询：输完关键词按回车直接筛，不用再去点按钮。

3. 跟进回访：把"下次再说"变成"下次什么时候"

每次联系录一条跟进：时间、方式（电话 / 微信 / 到店 / 短信）、聊了什么、客户反馈、下次回访时间、有没有报价。新线索跟完一次自动变成"跟进中"。同一个客户的跟进按时间正序排成一条时间线，最新一条显示在档案最上面。

跟进回访：按时间、方式、归属销售筛选，逾期的标红
跟进记录：方式、内容、反馈、下次回访时间一屏录完
  • 只增不改不删：要补充就再加一条"补充说明"，沟通链永远完整，谁也不能事后改口。
  • 到期自动提醒：回访时间一到就进首页清单，逾期显示拖了几天，销售主管一眼看出谁在偷懒。
  • 能导出：按时间、方式、销售导成 Excel，做复盘或者交接都用得上。

4. 试驾管理：到店了别只倒杯水

客户上车试驾，就登记一张试驾单：客户、试驾车型、试驾时间、陪同销售、证件是否核验、试驾路线、试驾反馈、有没有生成报价。登记后客户状态自动进"试驾"。列表能按时间和车型筛，谁陪的试驾、客户什么反应，都留得下来。

试驾管理：试驾时间、客户、车型、陪同销售、反馈摘要
登记试驾：绑定客户与车型，证件核验与路线一并记录
  • 必须绑客户和车型：不会出现"试了台车但不知道是谁"的糊涂账。
  • 证件核验留痕：试驾前的证件核对记一笔，出了状况有依据。
  • 试驾反馈结构化：客户嫌贵还是嫌空间小，写进系统，下次跟进不用重新猜。

5. 成交订单：一台车一台车地记

成交订单号自动生成（DD-年份-序号），记客户、成交车型、车架号（17 位会校验）、成交价、定金、尾款（成交价减定金自动带出）、成交日期、交付计划、销售顾问。保存后客户状态直接置为"已成交"。列表底部固定显示当前筛选的成交笔数和金额合计。

成交订单：列表底部实时显示笔数与金额合计
录入成交：尾款自动算，车架号长度当场校验
  • 筛选即合计：改一下筛选条件，下面的笔数和金额马上跟着变，月底对账不用另开 Excel。
  • 导出带合计：导出的 Excel 首行就写合计金额，直接拿去交差。
  • 定金尾款分开记：收了多少、还差多少，一台车一台车清楚。

6. 战败客户：走了也要知道为什么走

客户明确不买了或者去别家订了，就登记战败：选原因（价格偏高 / 选择他店 / 暂不购车 / 家人反对 / 其他），写两句说明。战败客户从线索池移出、进单独的列表，但全部历史记录都保留。哪天客户又回来了，管理员一键"恢复为线索"，重新进跟进流程。

战败客户：按原因、时间、归属销售筛选
战败登记：选原因 + 写说明，动作写入操作日志
  • 战败原因能统计：一个月里"价格偏高"占一半，说明该调政策了，不是销售不努力。
  • 恢复要管理员操作：普通销售不能自己把战败客户捞回来重算业绩。

7. 客户档案：一个客户一页看完

客户档案是单个客户的一页式全景：基本信息卡、漏斗状态条、最近一次跟进摘要、完整跟进时间线、试驾记录、成交订单、附件。右上角三个动作——新增跟进、登记试驾、录入成交，按客户当前状态自动显隐（已经成交的客户就不会再显示"录入成交"）。

客户档案：资料、状态、跟进时间线、试驾与成交记录一页聚合
  • 换人接手不掉链：销售离职把客户转给别人，接手的人打开档案就能看到全部经过。
  • 不用来回跳页：想跟进、想登记试驾、想录单，都在这一页上点，不用先去菜单里找。

8. 统计报表：谁出单、谁掉队，按人看得清

报表中心按销售顾问维度统计：线索量、试驾量、成交台数、成交金额、转化率（成交 ÷ 线索）、战败率（战败 ÷ 线索）。默认看本月，也能自选起止日期。线索量还配了横向条形对比，谁的线索多、谁的转化高，一根条就看出来。

统计报表：按销售顾问统计线索、试驾、成交、转化与战败
  • 转化率比台数更有用：线索多但转化低，和线索少但转化高，是两种完全不同的管理动作。
  • 导出带口径说明：报表导出的 Excel 会写清统计口径和生成时间，拿去汇报不会被追问"这数怎么来的"。

9. 账号、设置与日志：谁能看什么，都有规矩

只有两种账号：管理员和普通销售。普通销售看不到账号管理、系统设置、操作日志三个菜单，也不能删客户、不能作废订单、不能恢复战败客户——菜单和按钮是真隐藏，不是灰着。

账号管理：新增账号、设定角色、重置密码、启用停用
系统设置：个人设置、字典维护（车型 / 来源 / 战败原因）、关于
操作日志：记录到人，留最近三个月，可筛选可导出
  • 人员离职停用不删除：历史客户和日志的归属关系不断，账不会乱。
  • 字典自己维护：车型、线索来源、战败原因都能改，停用的选项不再出现在下拉里，历史数据照样保留。
  • 密码有防护：密码加盐哈希存储，连续 5 次输错锁 10 分钟，锁定也记日志。
  • 日志留三个月：登录、增改客户、跟进、试驾、成交、战败、账号变动、字典变更全都记，超期自动清理。

适合哪些人用

只要你的生意是"客户留电话—销售反复跟—到店成交"这个循环，并且客户资料不想放到别人服务器上，就适合。

汽车 4S 店 / 品牌店

销售顾问多、线索来源杂，最需要按人统计转化率，也需要防止客户被带走到别的店。

汽贸店 / 综合展厅

一人身兼销售和接待，回访全靠脑子记，一个待回访清单能救回不少订单。

新能源直营 / 城市展厅

试驾环节重，试驾反馈和证件核验要留痕，方便复盘哪台车客户最买账。

二手车 / 商用车门店

客户决策周期长，跟进动辄十来次，时间线和到期提醒比什么都重要。

说清楚不合适的情况：需要集团多门店联网、总部统一看数、手机端跑外展、对接厂家 DMS 或财务系统、需要微信自动群发营销的，这类更适合云端 CRM。客销管家的定位是把一家门店的客户资料留在自己电脑里——单机、离线、不走服务器，客户名单不会跟着销售一起流失。

常见问题

Q：客户资料、成交价这些数据会上传吗？

A：不会。全部数据保存在本机的 SQLite 数据库文件（autocrm.db）里，软件不主动联网、不上报任何信息，断网状态下功能完整可用。

Q：没激活能用吗？

A：未激活时会停在授权激活页，粘贴有效授权码后才能登录使用。授权码绑定本机机器码，一机一码，不能拿到别的电脑上用。

Q：销售能看到别人的客户吗？

A：默认看不到。普通销售的首页和列表只统计本人数据，客户线索、跟进、档案都按归属过滤；主管和管理员账号可以看全店。账号管理、系统设置、操作日志三个菜单对普通销售直接不显示。

Q：销售离职了，他手上的客户怎么办？

A：账号设成"停用"而不是删除，他的客户和历史日志都还在。管理员把客户改派给在职的人，接手的人打开客户档案就能看到全部跟进经过。

Q：跟进记录能改或删吗？

A：不能。跟进只增不改不删，要补充信息就再加一条"补充说明"。这样沟通链不会被事后修改，出了问题查得到原始记录。

Q：客户跑单了怎么办？

A：登记战败并选原因（价格偏高 / 选择他店 / 暂不购车 / 家人反对 / 其他）。战败客户单独列表留存，历史记录全在；客户回头时管理员可以一键"恢复为线索"，重新进跟进流程。

Q：数据多了会不会卡？

A：按 2 万条客户、5 万条跟进的规模做过设计，列表首屏 1 秒内出，条件查询 1.5 秒内出，导出 5000 行 Excel 十秒内完成。常用查询字段都建了索引。

Q：数据怎么备份？电脑坏了会不会全丢？

A：系统设置里有"备份数据库"和"还原数据库"，备份会生成带日期时间的 .db 副本，路径可自定义。建议每天营业结束备份一次，拷到U盘或另一台电脑。

Q：换电脑了怎么办？

A：授权码绑定本机机器码，换电脑需要重新申请。具体规则和迁移方式请参考统一售后页面。

Q：装不上 / 杀毒软件报毒怎么办？

A：单机小工具可能被部分杀软误报，可先加入信任列表再运行。遇到无法解决的问题，请通过售后页面联系处理。
