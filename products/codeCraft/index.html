功能详解：四步走完一张标签

下面是软件里的真实界面（数据为演示数据）。生成码 → 存模板 → 批量出图 → 打印标签，一件商品三十秒。

1. 首页：二维码和条码，两台"生成机"并排放

打开就是快速生成页，左边二维码、右边条码，参数改一下预览立刻变，不用先点"生成"再看结果。常用的活儿都在这一屏，不用翻菜单。

二维码快速生成：内容类型、尺寸、纠错等级、颜色、中心 LOGO
条码快速生成：类型、高度、是否显示数字与字号
  • 二维码内容支持 6 种：文本、网址链接、微信收款码、手机号、WiFi 信息（名称+密码）、自定义 JSON（溯源）。选好类型按提示填，不用背编码格式。
  • 参数都能调：尺寸 80~400px 拖动调节，纠错等级 L/M/Q/H 可选，前景色背景色自定义；要放自家 LOGO，就上传一张小图居中压上去。
  • 条码三种主流制式：Code128（最通用，默认）、EAN-13（13 位商品国标码）、Code39（老系统兼容），高度、数字显示、字号都可以改。
  • 生成完可以复制、导出图片、加入商品模板，一步接一步，不用换页面。

2. 商品模板库：常卖的那几十个货，建一次就够

把商品名、规格、售价、条码内容、二维码内容存成模板。下次不用重新抄一遍编码，搜一下打开，条码和二维码同时渲染好，直接打印或导出。

商品模板：字段一次填全，双码内容一起存
商品模板库：搜索、编辑、一键打开直接渲染
  • 字段就是做生意那几样：模板名称、商品名称、规格、售价、条码内容、二维码内容、备注，没有多余的必填项。
  • 改价只改模板：调价时改模板里的售价，不用重新生成码，重新打印一张就是新价签。
  • 支持搜索与一键打开：货多了也能两秒找到那一个。
  • 试用版最多存 5 个模板，买断后不限条数。

手动多行输入，或者直接导入 CSV（用 Excel 整理好再导）。一次生成整批条码/二维码，一键把全部图片导出到指定文件夹，不用一个个右键另存。

4. 标签打印：选好纸，直接出纸

内置两套标签模板——A 款条码价格标签、B 款双码标签（条码 + 二维码 + 商品信息）。这一版刻意没做拖拽编辑器：模板固定、参数可调，反而更省事，不会调一晚对不齐。

  • 直接调用系统打印机：热敏标签机和普通 A4 打印机都能打。

授权采用 Ed25519 离线签名验签——不用连服务器校验授权，断网的车间、仓库、摊位照样能用。数据备份是把本地数据库和模板图片加密打包，换电脑恢复即可。

常见问题

Q：导出的图有水印吗？能商用吗？

A：没有水印。导出的是干净 PNG / JPG，用在自家商品的包装、标签、详情页上没问题。图是你自己生成的，软件只是工具。

Q：会不会偷偷上传我的商品信息？

A：不会。软件不联网也能完整使用——授权是离线验签，商品模板和导出记录都存在本机 SQLite 文件里，没有任何上报接口。

Q：换电脑了怎么办？

A：授权绑定本机机器码，换电脑需要重新签发授权串，每年最多 3 次换绑。把机器码发给我们，走售后页面处理即可。同机重装系统不用重新买。

Q：支持哪些条码和二维码内容？

A：条码支持 Code128、EAN-13、Code39；二维码支持文本、网址链接、微信收款码、手机号、WiFi 信息、自定义 JSON 六类。只做静态码，不做动态跳转。

Q：标签纸打印对不齐怎么办？

A：内置 40×30、50×30 等常见热敏纸尺寸预设，边距可以微调。先看预览再出纸，调一次存下来，以后直接用。

Q：我完全不懂电脑，能学会吗？

A：整个软件就五个页面：快速生成、商品模板库、批量生成、标签打印、系统。选类型、填内容、点导出，正常十分钟能上手。试用免费，学不会不花钱。

Q：杀毒软件报毒怎么办？

A：单机小工具偶尔会被误报，加入信任列表再运行即可。遇到无法解决的问题，通过售后页面联系我们。
