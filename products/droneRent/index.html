设备租出去容易，收回来才算真本事

撞档期、验机扯皮、电池老化了没人记、配件少了说不清、押金退多少全靠估——无人机租赁的坑，几乎都在这几件事上。

飞租通把一单租赁拆成一条链：客户和资质先过合规，下单锁设备档期，出库时给设备拍一遍基线照片，归还时按模板逐项验机并和出库照片对比，有异常就转维保工单，最后押金抵扣、出结算单。每一步都写进同一个本地数据库，出了纠纷翻记录就行。

功能详解：跟着一单租赁走一遍

下面都是软件里的真实界面（数据为演示数据）。客户建档验资质 → 下单锁档期 → 出库配组拍照 → 归还验机 → 异常转维保 → 押金结算，就是完整的一单。

客户 + 资质→ 下单锁档期→ 出库配组拍照→ 归还验机→ 维保 / 复验→ 押金结算

1. 工作台：今天该出库、该收机、该催结算

登录第一屏。今日订单数、今日租金收入、进行中订单、待归还设备、待结算订单、库存预警六块数据，加上按紧急程度排好的待办：出库、归还、验机、维保、保险到期、资质到期。五个快捷入口直接开工，下面还有最近租赁订单列表。

工作台：今日经营数据 + 待办提醒 + 快捷入口 + 最近订单
  • 待归还优先显示超期：该收的机没回来，比什么都急，排在最前面。
  • 今日数据按本机日期算：不受时区、网络影响，开机就是这个数。
  • 预警阈值自己设：配件、电池、设备低于安全库存都会亮出来。

2. 客户与资质：不合规的客户，单开不下去

客户分企业客户和个人客户，企业记单位名称、统一社会信用代码、联系人、电话、地址；个人记姓名、身份证号、电话、地址。营业执照、身份证、操控员执照都能上传存档，并记录资质有效期。到期前 30 天、15 天、7 天分级提醒，黑名单客户禁止下单或需要特殊审批。

客户档案：企业 / 个人两类，支持 Excel 导入
资质管理：执照、身份证、操控员证一档留存
资质到期提醒：30 / 15 / 7 天分级预警
  • 信用分自动算：按消费金额、违约次数、逾期归还次数、赔偿记录算出 A / B / C / D 四个等级。
  • 等级影响押金：不同信用等级对应不同押金比例或免押额度，调整要写原因。
  • 停用不删除：客户停用后不能新增订单，历史订单和押金记录照样查。

3. 租赁订单与档期：从下单到结算六个状态

新建订单选客户、设备、机型、租期和操作员，系统自动算租期天数和租金（按机型、租期、附件数量）。订单状态走：待确认 → 待出库 → 进行中 → 待结算 → 已结算，中途可取消并释放档期。未出库前订单可改，出库后就不让动了。合同、出库单、签收单都能直接生成打印。

租赁订单：租期与租金自动算，状态一路流转
订单管理：按客户、设备、日期、状态组合查询
合同与单据：合同、出库单、签收单可生成打印
  • 档期冲突直接拦：同一台设备在租期内重复下单是下不进去的，不用人工核对日历。
  • 档期视图看占用：哪台机哪天被订走，一眼看清，也能倒查某段时间还剩哪些空闲设备。
  • 订单取消自动释放：不占用设备档期，别人马上能订。

4. 机型与设备台账：一台机一个 SN

机型档案记机型名称、品牌型号、基础参数（最大起飞重量、飞行时间、遥控距离）、日租 / 月租 / 超时费、押金标准、适用场景（航测、巡检、航拍、农业）。设备台账按 SN 逐台管理，记采购日期、价格、供应商、归属门店仓库、设备照片和折旧年限、当前净值。

机型档案：日租 / 月租 / 超时费与押金标准
设备台账：一台一个 SN，状态与归属一栏看清
  • 设备状态有六种：在库、已租出、维修中、保养中、保险过期、报废，状态就是能不能租出去的依据。
  • 折旧有记录：折旧年限和当前净值都在台账里，算单机效益时用得上。

5. 出库与归还验机：最容易扯皮的两步，做成标准动作

出库时按订单生成出库单，把主机、电池、遥控器、充电器等配组选好，给设备外观和关键部件拍基线照片，客户签收后设备状态转为已租出。归还时先登记归还时间，再按验机模板逐项检查——机身外观、桨叶、电池触点、遥控器、屏显模块、起落架、云台相机、IMU 校准、固件版本、定位模块、装箱清单、客户确认。

出库登记：设备与配件配组，出库基线拍照留档
归还验机：逐项检查，与出库照片对比，差异标红
  • 必拍项没拍完提交不了：验机靠模板卡住，不靠人自觉，该拍的照一张都跑不掉。
  • 新伤自动标红：归还照片和出库基线一对比，多出来的损伤直接标出来，客户在场上就说得清。
  • 结论联动下一步：合格回库，待复检转维保，客户责任直接生成赔偿或扣款。
  • 模板按机型配：不同机型可以设不同验机模板，每项能设普通项、必检项、必拍项，改动留日志。

6. 维保管理：坏了修、修完验、验完才能再租

报修登记记来源（客户归还发现、例行检查、故障上报）、故障描述、现象截图、关联设备 SN 和订单、紧急程度。维修工单自动编号，分配给维保人员，记维修项目、配件费 / 工时费 / 检测费、责任归属（客户承担 / 保险理赔 / 公司自担），状态走待报价 → 待维修 → 维修中 → 已完成 → 待复验。修完返库复验通过，设备才恢复在库。

报修登记：来源、故障描述、紧急程度
维修工单：配件费 / 工时费与责任归属分开记
返库复验：不复验的设备不能重新出租
维保统计：故障率、单台维修成本、平均修复时间、配件消耗排行
维保记录：按设备 SN 追溯每一次报修与处理
  • 哪台机最费钱，查得到：按 SN 统计维修成本，一直修的机器该清退了。
  • 平均修复时间：从报修到修完多久，直接影响设备能租出去几天。
  • 责任分得清：客户弄坏的算客户，保险赔的走理赔，自己担的进成本，结算时不会糊在一起。

7. 电池与配件：最容易被顺手带走的东西

电池台账给每块电池独立编号，记采购日期、供应商、所在设备、循环次数、健康度、状态。健康度低于 80% 进告警，低于 60% 强制报废；鼓包、漏液、触点异常的电池直接锁定不能出库。配件库存管桨叶、遥控器、充电器、云台、屏显模块，下单时可预占，出库转实际出库，归还齐全回库，缺失的自动转赔偿单。

电池台账：循环次数、健康度、状态一目了然
电池管理：健康度告警与报废规则自动卡
配件库存：安全库存预警、呆滞分析与盘点差异
  • 电池不是消耗品，是要记账的资产：每块电池的循环和健康度都留着，什么时候该换心里有数。
  • 危险电池租不出去：告警电池要主管审批才能出，报废和异常电池直接锁死。
  • 配件少了自动转赔偿：归还时对不上装箱清单，直接生成赔偿单，不用事后追着客户要。
  • 库存流水可查：每一次入库、出库、赔回都有记录，月底盘点只核差异。

8. 保险与合规：该拦的单，系统帮你拦

保单管理记保单号、承保设备 SN、保额、保费、保险期间、受益人。合规检查覆盖五项：客户实名登记、操控员执照、设备保险、空域信息、客户承诺书。到期前 30 / 15 / 7 天分级提醒，过期后设备自动变成不可租。

合规检查：实名、执照、保险、空域、承诺书五项
合规规则：不达标时的拦截条件可配置
  • 四条硬拦截：客户资质过期不能下单、设备保险过期不能出库、操控员资质缺失不能下单、黑名单客户要特殊审批。
  • 拦截给原因：不是一句"操作失败"，而是告诉你缺哪一项，补完就能继续。
  • 保险过期自动锁：不靠人记，到期那天设备就租不出去了。

9. 押金与结算：退多少、扣多少，一条条列出来

押金按机型和客户等级定标准，收取时登记金额、方式、时间并关联订单，租期内冻结不可退。抵扣分五类：超时费、清洁费、损伤赔偿、丢失赔偿、配件缺失赔偿。验机合格后才能退款，退款记录金额、方式、时间、收款人，大额退款要审批，退完订单转已结算。

押金收取：按机型与客户等级定标准并登记
押金登记：金额、方式、时间与订单绑定
押金抵扣：超时、清洁、损伤、丢失分项扣
押金退款：验机合格才可退，大额需审批
结算单：租金、超时、赔偿、维修、押金抵扣与应收合计
结算记录：按订单追溯历史结算与押金往来
  • 结算单九项列全：订单租金、超时费、配件赔偿、维修费、保险费、押金抵扣、应收合计、已收、未收。
  • 抵扣有依据：每一笔扣款都能追到验机结论或维保工单，客户问就翻给他看。
  • 大额退款要审批：避免店员随手把钱退出去。

10. 统计分析：哪个机型赚钱、哪台机在吃灰

经营概览看租金收入、订单数量、出租率、毛利率、回款金额和押金余额；机型效益看出租率、收入贡献、扣除成本后的毛利、维修费用分摊，还会给"增购 / 清退 / 重点保障"的建议；单机效益把每台设备的收入、维修成本、折旧、毛利和利用率算到台；客户贡献看租赁频次、累计消费、押金余额和违约记录。

经营概览：收入、订单、出租率、毛利率
机型效益：出租率、毛利与增购 / 清退建议
单机效益：每台机的收入、维修、折旧与毛利
客户贡献：频次、累计消费、押金余额与违约
经营报表：按周期汇总，支持导出 Excel
报表导出：经营、订单、设备、维保、库存、结算六类
  • 出租率是核心指标：设备实际出租天数除以可租天数，比单纯看收入更能反映生意好坏。
  • 机型建议直接用：哪个该增购、哪个该清退，报表里给了判断，不用自己推。
  • 六类报表都能导：经营、订单、设备、维保、库存、结算，导出 Excel 给财务或自己做分析。

11. 系统设置与操作日志：数据归自己管

系统设置管门店仓库、价格与押金、验机模板、用户权限、打印模板和数据备份。操作日志只读，记操作时间、操作员、模块、动作类型、业务单号、关键内容、本机标识，留 24 个月，支持按模块、操作员、时间、单号查询和导出。日志还能按订单号、设备 SN、客户三种线索串起整条链路。

门店仓库：门店与仓库信息、地址联系人
价格与押金：日租、月租、超时费、赔偿价
验机模板：新增验机项，设必检与必拍
用户权限：账号、角色、菜单与数据权限
打印模板：出库、归还、验机、合同、结算、收据
数据备份：一键备份、自选路径、恢复二次确认
  • 备份是自己的事：数据就在本机那个 .db 文件里，建议定期备份并且异地存一份。
  • 日志能串链路：一笔订单从开单、出库、归还、验机、维保到结算，按单号能一路查下去。
  • 权限分得开：业务员只管开单出库收机，价格、结算、授权留给管理员。

适合哪些人用

只要你的生意是"同一批设备反复租给不同客户"，并且设备贵、押金高、验机容易扯皮，就适合。

无人机租赁门店

十几台到几十台机，一天进出几单，最怕档期撞车和验机没依据。

航测 / 巡检服务商

设备按项目外租，客户是工程单位，资质与保险合规不能含糊。

航拍工作室

机器多、配件散，电池和桨叶最容易流失，需要台账和赔偿依据。

农业植保队

季节性强、机器使用强度大，维保成本和单机效益必须算清楚。

说清楚不合适的情况：单机版面向单店本地使用，不做多门店联网、不支持多台电脑同时连同一个数据库、不做手机端和客户自助下单、不接无人机厂家后台、不做在线支付与银行代扣。需要跨店调度、多人异地协作的，属于网络版范畴。飞租通单机版的定位是一家租赁门店、一台电脑，把设备从租出去到收回来管清楚。
上面这些"不合适"，有一部分是能改的。如果这款软件和你店里的流程差一两步——多一个字段、换一套单据格式、加一道审批、多一条业务线——都可以做定制修改开发，不必为了一个环节换掉整套工具。看看能定制什么 →

常见问题

Q：同一台设备能被两个客户订到同一天吗？

A：不会。下单时系统按设备 SN 校验档期，租期重叠会直接拦住。维修、保养、保险过期的设备也会自动锁定，租不出去。

Q：客户把机器磕了，怎么证明是这次弄的？

A：出库时拍一遍基线照片，归还时按验机模板逐项检查并拍照，系统把归还照片和基线照片对比，新增损伤标红。必拍项没拍完，验机提交不了——证据是流程逼出来的，不靠人自觉。

Q：电池怎么管？

A：每块电池独立编号，记循环次数和健康度。低于 80% 进告警（要主管审批才能出库），低于 60% 强制报废；鼓包、漏液、触点异常的电池直接锁定，出不了库。

Q：没激活能用吗？

A：能打开软件、查看界面，但新增、修改、保存、结算、打印、导出都不可用，正式使用前需要完成激活。

Q：押金抵扣会不会算不清？

A：抵扣分五类：超时费、清洁费、损伤赔偿、丢失赔偿、配件缺失赔偿，每一笔都能追到验机结论或维保工单。结算单把租金、超时、赔偿、维修、保险、押金抵扣、应收合计、已收、未收九项全部列出来。

Q：客户资质过期了还能下单吗？

A：不能。客户资质过期、操控员执照缺失、设备保险过期这三种情况都会在下单或出库时被拦住，并告诉你缺哪一项。黑名单客户需要特殊审批才能下单。

Q：几个店员能一起用吗？

A：同一台电脑可以，按角色分权限：业务员开单、出库、收机、登记收款；维保人员处理报修和复验；价格、结算、授权、备份留给管理员。多台电脑同时用同一个数据库不支持。

Q：电脑坏了数据会丢吗？

A：取决于有没有备份。系统设置里可以一键备份 SQLite 数据库到自选路径，恢复要二次确认。建议定期备份并异地存一份——单机版的数据安全，最终靠这个动作。

Q：操作记录能查多久？

A：操作日志留 24 个月，只读、不可编辑。可以按模块、操作员、时间、业务单号查询并导出，还能通过订单号、设备 SN、客户三种线索串起整条业务链路。

Q：换电脑了怎么办？

A：授权绑定机器码，换机要重新申请。步骤：旧机备份 → 备份文件拷到新机 → 新机装软件取新机器码 → 重新签发授权 → 激活后恢复数据。
