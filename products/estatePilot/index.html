物业的活不难，难在账和事对不上

收费员记一本、前台记一本、工程师傅记在手机备忘录里——月底主管想看一眼收缴率，得把三个人的记录凑到一起。

物管通把"房屋与业主档案"做成唯一的主数据，收费、报修、停车、访客四条线全部挂在房号上。收费员录一笔收款，欠费清单和收缴率报表同时变；前台登记一张报修单，工程的工单列表里立刻能看到；主管打开首页，应收、实收、未完成工单就在那儿摆着。

功能详解：按物业的一年走一遍

下面都是软件里的真实界面（数据为演示数据）。房屋建档 → 业主入住 → 按期计费 → 收钱或欠费 → 催缴，同时并行走报修、停车、访客，就是物业的日常。

房屋建档→ 业主入住→ 按期计费→ 收缴 / 欠费→ 分级催缴→ 台账与报表

1. 首页看板：六张卡回答两个问题

登录第一屏就是看板。总户数、欠费户数、本月应收、本月实收、待处理工单、今日新增报修六个数字，加上本月收缴率——"这个月收得怎么样、还有哪些事没做完"，五秒能判断。下面两块清单直接可操作：左边待催缴业主，右边待处理工单。

首页看板：六张指标卡 + 待催缴清单 + 待处理工单清单
  • 数字是真算的：全部由数据库实时聚合，改一条收款，看板上的实收和收缴率立刻跟着变。
  • 待催缴按金额倒序：欠得最多的排最前，催收的先后顺序不用自己排。
  • 两个入口直接干活："去催缴""去处理"点进去就是对应页面，不用先去菜单里找。

2. 房屋与业主档案：先有房，才有后面所有的账

房屋按楼栋、单元、房号三级组织，记建筑面积、房屋性质（住宅 / 商铺 / 办公）、状态（空置 / 已入住 / 出租）、交付日期。同一楼栋单元内房号唯一，录重了会直接拦住。业主与房屋绑定，一套房一名主业主，可以再登记家庭成员或共有人。

房屋档案：楼栋 / 单元 / 房号三级，可按楼栋汇总户数与面积
新增房屋：面积、性质、状态、交付日期一次录清
  • 业主档案聚合视图：一套房的缴费、欠费、报修、访客记录都归在这页，业主上门问事不用翻几处。
  • 附件能传：证件照、租赁合同传上去，单张不超过 5MB，可多张。
  • 批量导入：按模板导楼栋、单元、房号，导入结果会告诉你成功几条、失败几条、为什么失败。

3. 物业费收缴：用得最多的就是这一页

收费按"房屋 + 收费项目 + 费用期间"算一笔应收。选房、选项目、选期间，应收金额自动带出（要改必须填调整原因）；录实收、收费方式、收费日期、收费员、票据号，收据直接打印。实收比应收少，系统自动生成欠费；一样多就置为已结清。

收费台账：应收 / 实收 / 欠费三个口径并排
底部汇总栏：应收、实收、欠费合计随筛选实时刷新
收费录入：选房带出应收，改价必须填原因
  • 不会重复收：同一房屋、同一项目、同一期间只允许一笔应收，重复录入会提示"该期间费用已登记"。
  • 收费项目自己定：物业服务费按面积、公共能耗按户、垃圾清运和电梯费按年、车位管理费按车位、装修管理费一次性——计费方式和周期都能设。
  • 汇总口径不骗人：底部合计按当前筛选结果实时算，不读全量数据，导出 Excel 的范围和汇总完全一致。

4. 欠费催缴：欠得久了，得有人管

欠费由"应收减实收"自动识别，按天数分三级：1–30 天轻度、31–90 天中度、90 天以上重度。欠费清单按房号排，显示欠费总额、最长欠费天数和联系电话。催缴可以按项目设"到期前 N 天提醒"（默认提前 7 天），每次催缴登记方式（电话 / 上门 / 短信）、催缴人、业主答复。

欠费清单：总额、最长欠费天数、联系电话一屏看完
催缴记录：时间、方式、催缴人、业主答复，只增不改
欠费分级：轻度 / 中度 / 重度三档，催收优先级清楚
  • 催过就有记录：谁在什么时候催的、业主怎么答复的，都留在系统里，业主再说"没人通知我"时有话说。
  • 结清自动移出：钱一收，这户自动从待催缴清单消失，不用手工勾。
  • 催缴量能统计：一个月打了多少电话、上门几次，看得到工作量。

5. 停车管理：车位、车辆、到期提醒

车位档案记编号、类型（固定 / 临时 / 人防）、所属区域、绑定房号、月租金、状态。车辆记车牌号、车牌颜色、车辆类型、绑定业主、联系电话、停车费到期日。停车费按车位月租金生成应收，和物业费共用同一套收费录入与台账。

停车管理：车位与车辆台账，到期前 7 天提示续费
新增车位：类型、区域、绑定房号、月租金
登记车辆：车牌校验并唯一，绑定业主与到期日
  • 车牌不会录错：格式校验 + 唯一约束，同一个车牌不会出现两辆车。
  • 到期提醒双处显示：首页和停车列表同时提示，避免业主进出被拦才发现过期。
  • 临停只登记不收费：临时车辆记进出时间按小时计费，不参与月度应收，不干扰月账。

6. 报修工单：从登记到完工，一张单到底

前台登记时报房号（或公共区域）、报修类型、内容、紧急程度、联系电话，可以拍现场照片。工单号按年流水生成（WX-2026-0001）。派单时指定维修人员，修完填处理结果、使用材料、完工时间；修不了的填驳回原因（不少于 10 字），前台回访后再重新派单或转外委。

报修工单：按状态、类型、楼栋、时间筛选，底部汇总各状态条数
报修登记：房号、类型、内容、现场照片一次录完
  • 四态流转清楚：待派单 → 维修中 → 已完成，处理不了的转驳回，不会出现"单子不知道去哪了"。
  • 照片就是证据：漏水点、门禁故障拍下来挂在工单上，材料用了多少也记着，避免事后争议。
  • 完工单删不掉：已完成的工单不允许删除，要冲正得管理员操作并写日志。

7. 访客登记：值班室那一本，搬进电脑

访客姓名、手机号、来访房号、被访业主、来访事由、来访时间、离开时间、登记人，一条条记下来。离开时间没填的，列表里标成"在场"——值班交接时一眼看出还有谁在小区里没走。

访客登记：未离开的标"在场"，可按日期、房号、姓名检索
访客录入：来访房号与被访业主关联到房屋档案
  • 交接不断档：换班时看一眼"在场"清单，不用口头交代"还有两个人在 3 号楼"。
  • 能和业主对上：访客记录挂在房号上，业主档案里也能看到谁来访问过。

8. 收支台账与公告：经营账和通知都在一套里

收支台账记非收费类收入和全部支出：收入分物业费（由收费模块汇总并入，不重复录）、停车费、广告位、场地租赁、其他；支出分工资、保洁耗材、维修材料、公共能耗、办公费用、其他。月度汇总看收入合计、支出合计、结余，还能按类别展开占比。公告用来发布停水停电、电梯年检、缴费提醒这些通知。

公告通知：生效 / 失效日期管理，过期自动失效但留档
发布公告：标题、正文、类型、生效与失效日期
  • 收入不重复算：物业费只在汇总时并入，不逐笔再录一遍，不会把营收算成两倍。
  • 凭证能留：每笔收支都能挂凭证附件，查账时有据可依。
  • 公告是内部存档：发布、打印张贴、留档，不对外推送——想要业主端推送得上云端系统。

9. 统计报表：三类报表，口径和台账一致

物业费收缴报表（应收、实收、欠费、收缴率，按楼栋与项目分组）、报修工单报表（工单总量、完成率、平均处理时长、类型占比）、收支汇总报表（收入、支出、结余、分类占比）。都能选统计区间、按楼栋或人员筛选、导出 Excel。

统计报表：收缴率、工单完成率、收支结余一张屏对比
  • 两套数字的问题没有了：报表直接读台账数据，不二次加工，台账改了报表就跟着变。
  • 空数据也写清楚：没数据的楼栋显示 0 和 0.0%，不会留白让你以为漏了。
  • 月报十分钟出完：以前要三个人凑数，现在选个区间导出就行。

10. 账号、设置与日志：谁能看什么，一次配好

账号一人一号，按岗位分角色。系统设置是独立页面（不弹窗），四个页签：基础参数（小区名称、收费默认周期、催缴提前天数、收据抬头与编号规则）、字典维护（收费项目、报修类型、收支分类、车位类型）、账号与安全、关于。操作日志记录登录、收费冲正、工单派单完工、字典变更、激活等动作，留三个月。

账号管理：一人一号，角色可调，停用不影响历史数据
系统设置：基础参数、字典维护、账号与安全、关于
操作日志：只增不改，留三个月，可查询可导出
  • 字典项删不掉会有提示：被业务数据引用的收费项目、报修类型禁止删除，并告诉你有多少条在用。
  • 权限是双层的：界面藏起入口只是第一道，后台每个接口还会再校验一次角色。
  • 每天自动备份：启动时自动备份到 backup 目录，保留最近 30 份，误删数据能找回最近的。

四种角色，各看各的

同一台电脑上能切换账号，数据随角色可见。收费员看不到收支台账，工程看不到工单以外的东西，普通员工只能查。

管理员

物业主管 / 经理

全部权限：档案、收费、工单、报表、账号、系统设置、操作日志、授权激活。

收费员

前台 / 财务

收费录入与查询、欠费催缴、停车收费部分、访客登记；看收费相关报表，收支台账只读。

工程维修

维修师傅

接单与完工、填处理结果与材料；房屋与业主档案只读，看工单相关报表。

普通员工

值班 / 内勤

只拿查询权限：看档案、看欠费清单、看公告，不参与任何数据写入。

权限可以随时调：角色在创建账号时指定，管理员随时改，改完立刻生效。人员离职把账号停用，历史收费记录和操作日志的归属关系都保留，查账不断线。

适合哪些小区和物业公司用

只要是"一个小区、一套人、按月收物业费"的场景，并且不想按年付订阅费，就适合。

中小物业公司

管一两个小区，老板自己盯收缴率，几个人分工干活，不需要买一套几万块的系统。

单小区自管

业委会自聘或开发商自持，收费员加一个维修师傅，Excel 管到几百户就开始出错。

安置房 / 老旧小区

住户结构复杂、欠费多、催缴靠打电话，最需要欠费分级和催缴记录。

商住混合 / 公寓

住宅、商铺、办公混在一起，不同性质单价不同，需要按面积和按户分别计费。

说清楚不合适的情况：V1.0 不做业主端 App 和微信小程序（业主不能自助缴费）、不做在线支付与银行代扣、不做电子发票、不接门禁道闸硬件、不支持多小区集中管理（一个小区对应一个数据库文件，管多个小区就分别安装、各用各的库）。如果你要的是"业主手机上交钱、总部统一看数"，那更适合云端物业系统；物管通的定位是一套人、一个小区、一台电脑，把日常账和事管清楚。

常见问题

Q：收费和业主数据会上传吗？

A：不会。数据全部保存在本机的 SQLite 数据库（estatepilot.db）里，默认放在 %APPDATA%\EstatePilot\ 目录，附件也在同目录的子文件夹。软件不联网、不上报任何信息。

Q：业主能在手机上交物业费吗？

A：不能。V1.0 是收费员在系统里登记收款、打印收据，业主侧不操作系统，也不接微信支付和银行代扣。业主自助缴费属于云端系统的事，这一版不做。

Q：我有三个小区，能放一个系统里吗？

A：不支持多小区集中管理，一个授权对应一个小区的数据文件。三个小区就分别安装、各用各的库，各自授权。好处是数据互不干扰，出问题也只影响一个小区。

Q：收费项目能自己改吗？比如住宅和商铺单价不一样。

A：能。收费项目由管理员在系统设置里维护，计费方式支持按面积 / 按户 / 按车位，周期支持月 / 季 / 年，停用的项目不再出现在下拉里但历史记录照常显示。住宅和商铺可以建两个不同单价的物业服务费。

Q：应收金额算错了想改怎么办？

A：可以手工调整，但必须填调整原因，改了什么、为什么改都留在记录里。这样既留了灵活性，也不至于事后说不清。

Q：同一户重复收了一次费怎么办？

A：同一房屋、同一项目、同一期间系统只允许一笔应收，重复录入会直接提示"该期间费用已登记"。已经收错的，由管理员做冲正操作并写入日志。

Q：报修单流程是怎样的？师傅能自己接单吗？

A：前台登记 → 管理员或主管派单给维修人员 → 维修中 → 填处理结果和完工时间 → 已完成，主管可补备注复核。修不了的转驳回（驳回原因不少于 10 字），前台回访后重新派单或转外委。

Q：数据会丢吗？

A：每次启动自动备份一次到 backup 目录，保留最近 30 份并按日期命名。也可以手动"导出数据库"另存一份。真误删了，用最近一次备份恢复。

Q：一千户会不会卡？

A：按单小区 1000 户、收费记录 5 万条的规模设计：列表首屏 1 秒内加载，筛选与汇总 0.5 秒内出，导出 1000 行 Excel 5 秒内完成。

Q：换电脑了怎么办？

A：授权一机一码，换电脑需重新取机器码申请授权码，原授权失效。数据可以带着走：把数据库文件和 attachments 目录一起拷到新电脑对应位置即可。

Q：装不上 / 杀毒软件报毒怎么办？

A：单机小工具可能被部分杀软误报，可先加入信任列表再运行。遇到无法解决的问题，请通过售后页面联系处理。
