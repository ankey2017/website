功能详解：跟着一场直播走一遍

下面都是软件里的真实界面（数据为演示数据）。备货建档 → 开播建场 → 录单扣库存 → 发货运样 → 退货处理 → 复盘结算，就是一场完整的直播。

商品与 SKU→ 建场次→ 录单扣库存→ 发货 / 退换货→ 直播复盘→ 佣金结算

1. 工作台：今天该干什么，六个数字说清

登录第一屏。今日订单、今日销售额、待发货、待售后、进行中场次、库存预警六张卡，下面还有近 7 天和近 30 天的销售趋势。五个快捷入口直接开工：新建场次、录入订单、样品领用、库存查询、立即备份。

工作台：六张指标卡 + 销售趋势 + 快捷入口 + 待办与备份提醒
  • 待办直接可点：待发货、待售后、超期未还的样品、库存预警，点一下跳到对应列表，不用自己找。
  • 备份提醒会变黄：超过 7 天没备份就提示你，点一下直接进备份页面——单机版最怕的就是电脑一坏数据全没。
  • 进行中场次常驻：正在播的那一场就在工作台上，随时切进去录单。

2. 商品与 SKU：成本和直播价分开记

商品建档记编码、名称、分类、单位、图片、成本价、日常售价、直播价、预警库存和默认供应商。有规格的按规格生成 SKU，每个 SKU 有自己的编码、库存和成本；没有 SKU 的按单规格算。图片会复制到数据目录，源文件挪走也不会失效。

商品档案：成本价 / 日常售价 / 直播价三档分开记
SKU 管理：按规格拆开，各自独立库存与成本
  • 成本是快照的：录单时把当时的成本价写进订单明细，以后进货涨价，也不会把历史毛利算乱。
  • 编码唯一：同一个编码建不了两次，避免一人两个名字。
  • 能停用：不带的货停掉就行，历史订单照样查得到。

3. 库存与供应商：只能靠单据变，不能手改数字

入库有采购、退货回库、盘盈；出库有发货、样品领用、盘亏。每一次变动都写进库存流水：商品、SKU、变动类型、数量、变动前后库存、来源单据、操作人和时间。库存预警单独一个视图，低于预警值、零库存、负库存都列出来，可以直接导出补货清单。

库存管理：流水可追溯，预警列出该补的货
供应商管理：联系人、结算方式与供货商品
  • 数字对不上能查到底：每一件货的增减都有流水和来源单据，不是"凭空少了两件"。
  • 超卖会提示：库存不够时下单会拦住并提醒，比事后跟买家道歉体面。
  • 盘点生成差异流水：实盘录进去，差额自动记账，账实一致有依据。

4. 直播场次：一场一档，状态自己走

开播前建场次：标题、主播、平台、开播与计划下播时间、主推商品、备注。状态分待开播、直播中、已下播、已取消，点按钮开始和结束，时间自动记。同一个主播还有没结束的场次时，系统会提示先结束原来那场。

场次列表：按状态筛，开始与结束一键切换
场次登记：主播、平台、时间、主推商品一次填清
  • 先结束再开新场：避免一场的订单算到另一场头上，复盘数据才可信。
  • 主推商品提前定：播完能对照"主推的到底卖没卖动"。

5. 订单：录一单，库存跟着动

选场次后录买家、手机、地址、SKU、数量、实付、运费、来源，勾不勾样品单一目了然。保存即扣库存。订单多的时候可以用 Excel 模板批量导入，系统会校验必填列和商品是否存在，最后给你成功和失败的清单。未发货的订单能改数量金额并重算库存，已发货的只能改备注。

订单录入：明细可增行，合计与运费自动算
订单列表：按场次、主播、平台、时间、状态组合筛
  • 批量导入不背锅：哪几行失败、为什么失败都列出来，改完再导一次，不会导一半乱掉。
  • 状态流转清楚：待发货 → 已发货 → 已完成，退款走退款中 → 已退款，取消订单自动回补库存。
  • 改单有边界：发货前能改，发货后只能改备注，避免账实错位。

6. 样品领用归还：带货最容易被忽略的一笔成本

登记主播、SKU、数量、领用时间和预计归还时间，领用按成本价计入本场成本。归还的时候登记归还数量和时间，归还部分冲减成本；没还的标成损耗，单独统计。超期未还的会在工作台待办里提醒。

样品领用归还：领用、归还、损耗三件事在一张表里
  • 样品也是成本：不算这一笔，毛利永远是虚高的。
  • 超期能追：预计归还时间过了没还，待办里会点出来，不用靠问主播"那个样品还在吗"。

7. 发货与售后：发出去之后的麻烦事

发货登记录快递公司和单号、发货时间，支持批量发货，一单分多个包裹也能记。退换货分仅退款和退货退款，登记退回的商品数量、退款金额、原因和是否回库，选了回库库存自动加回来。退款会冲减发生期的销售额，并从佣金计算基数里扣掉。

发货登记：快递公司 + 单号，支持批量与分包
退换货管理：退款金额、是否回库一并处理
  • 退货自动回库：勾一下库存就加回来，不用手工再补一笔入库。
  • 退款不算佣金：退了的那部分从佣金基数里扣掉，主播和老板都不吃亏。

8. 直播复盘与佣金结算：这一场到底赚了多少

每场直播都能复盘：成交订单、销售额、成本、样品损耗、退款、毛利、客单价汇总在一页，还能写复盘笔记。佣金按主播设比例或固定金额，支持针对某个商品单独覆盖规则，并记录生效与失效时间。业绩单按周期汇总，点进去能下钻到每一笔参与计算的订单。

直播复盘：成交、成本、损耗、退款、毛利一页看完
佣金方案：按主播设比例或固定额，可按商品覆盖
主播业绩：成交额、退款额、应发佣金与明细下钻
  • 毛利是真毛利：里面已经减掉了商品成本、样品损耗和退款，不是只看销售额。
  • 结算记录只能作废：算错了作废重开，作废要填原因，账面上不会凭空少一条。
  • 主播排行：按周期看谁带得多、谁退得多，分钱的时候有依据。

9. 客户与对账：老客记得住，账目说得清

客户档案记昵称、手机号、收货地址、常用平台账号、标签和备注。客户详情里能看到全部订单、累计成交、累计退款和最近下单时间。重复的客户可以合并，订单和地址归到主档案，合并动作留痕。要跟某个客户对账，按时间段导出对账单就行。

客户档案：累计成交、累计退款、最近下单时间
客户对账：按时间段汇总下单、实收与退款并导出
  • 老客回头有印象：复购的客人一看历史就知道他上次买了什么、退过什么。
  • 重复客户能合并：同一个人的昵称和手机号各建过一次，合并后记录不丢。

10. 统计分析：哪个货好卖、哪场最赚钱

销售看板按日、周、月看销售额、订单量、退款额和毛利，可以切换平台。热销排行按销量或销售额排前 20 名，还带退货率——卖得多退得也多，那就不是好卖的货。场次对比能多场放一起比成交额、订单数、客单价和毛利率。所有报表都能导出 Excel。

销售看板：日 / 周 / 月切换，销售额与毛利并看
统计报表：区间与平台筛选，支持导出 Excel
热销排行：销量 / 销售额前 20 名，附退货率
  • 退货率一起看：只看销量容易选错主推，退货率高的货越推越亏。
  • 场次横向对比：同一批货换个时段播，效果差多少，一比就出来。

11. 设置、备份与打印：单机版最要紧的三件事

一键备份会调用数据库的在线备份接口生成一致性副本（不会因为正在写入而备出坏文件），文件名带日期时间戳；恢复前会先自动备份一次当前数据，恢复完要求重新登录。另外还有操作员账号（可以限制他看到成本和利润字段）、打印模板（小票 / 拣货单 / 发货单）、导出、操作日志和关于页面。

备份与恢复：显示数据路径与最近备份时间
打印模板：小票、拣货单、发货单字段可调
操作员账号：可隐藏成本与利润字段
导出：导出到本机自选目录，动作写入日志
  • 备份不是复制文件：用 SQLite 在线备份接口生成，正在开单的时候备份也不会坏。
  • 恢复有二次确认：会先展示备份时间、文件大小和数据条数让你确认，再自动留一份安全备份。
  • 店员看不到成本：操作员角色下成本和利润字段直接隐藏，不用担心毛利被看光。
  • 数据就在本机：数据库是 %AppData% 下那个 .db 文件，路径在设置里能看、能打开所在文件夹。

常见问题

Q：能自动同步抖音 / 快手后台的订单吗？

A：本期不做平台接口对接，订单靠手工录入或用 Excel 模板批量导入。导入时会校验必填列和商品是否存在，最后给你成功与失败清单。这样虽然少了一点自动，但不用申请接口权限，也不依赖平台改版。

Q：没激活能用吗？

A：能打开软件、浏览界面、看示例数据，但新增、修改、删除、导入、导出、打印、备份都要激活后才能用。也就是先看界面判断合不合用，正式录数据前完成激活。

Q：两个人能用同一套软件吗？

A：同一台电脑可以，管理员和操作员两个角色，操作员看不到成本和利润字段。但两台电脑同时连同一个数据库不支持——那是多机协作，得用网页版。

Q：库存能不能直接改数字？

A：不能。库存只能通过入库、出库、盘点三类单据变更，每次变更都写一笔库存流水。这是故意的——能直接改数字的库存表，三个月后一定对不上。

Q：退货之后佣金怎么算？

A：退款会冲减发生期的销售额，并从佣金计算基数里扣掉。所以主播业绩里的"成交额"是净额，不会出现退了货还按原价结佣金的情况。

Q：样品算成本吗？

A：算。领用按成本价计入本场成本，归还的部分冲减，没还的标损耗单独统计。不算这一笔，本场毛利就是虚高的。

Q：电脑坏了数据会丢吗？
