1. 首页仪表盘：每天开工先看这一屏

打开软件第一眼就是四组核心数字：客户总数、待回访客户、逾期回款项目、总欠款金额。下面两块看板分别列出「客户回访到期」和「项目回款到期」的具体名单——今天该打哪几个电话，屏幕上写着。

首页仪表盘：客户、回访、逾期回款、欠款总额集中呈现
  • 不用自己做计划：系统按你设的周期自动算出今天该跟进谁，省掉每天早上翻本子对日期的十分钟。
  • 逾期高亮预警：过期未回访、过期未回款的项目会被标出来，一眼看见，不会悄悄烂在表里。
  • 欠款总额直接看：所有项目加起来还差多少钱没收回，老板心里最该有数的就是这个数字。

2. 客户档案：把客户关系变成可查的资料

所有合作客户集中在一个列表里：客户名称、联系人、电话、客户等级、客户类型、负责人，同时显示该客户名下的项目数量。支持搜索筛选，也支持用 Excel 模板批量导入老客户。

客户档案：分级分类、负责人归属、关联项目数一目了然
  • 客户分级（A/B/C）：谁是好客户、谁是压价的、谁要盯紧，标出来之后精力分配更合理。
  • 客户类型区分：工程客户、维保客户、商贸客户分开管，跟进话术和周期本来就不一样。
  • 老客户一键迁移：以前记在 Excel 里的客户清单，套模板导入，不用一条条重新录。
  • 人员变动不怕：客户归到负责人名下，谁走了交接单拉出来就行，客户资源不会跟着人走。

3. 项目台账总表：每个项目值多少钱、还欠多少

所有项目集中在一张表：合同编号、合同金额、已回款、欠款、项目状态。欠款由系统自动算出来，不用自己拿计算器减。

项目台账：合同额、已回款、欠款、状态一屏掌握
  • 状态流转清晰：洽谈中 → 执行中 → 已完工 / 作废，翻一眼就知道手上还有几个活在跑。
  • 欠款自动计算：合同金额减去已回款，永远是当前真实数字，不会因为漏改一格就算错。
  • 按客户、按状态筛：想查某个客户名下所有项目，或者想汇总"执行中"的总合同额，两下就出来。
  • 导出给财务：台账表可导出，对账、报税、给合伙人看都有据可依。

4. 项目详情 + 回款计划：尾款就是这么收回来的

点开单个项目，能看到签约时间、负责人、合同信息；下面按项目录入多期回款计划（定金、进度款、尾款），每一期登记实际回款，计划回款和已完成回款分开显示。项目过程中的日志、合同扫描件、沟通记录也能一并归档在项目里。

项目详情：多期回款计划 + 实收登记 + 项目日志附件
  • 一单拆多期：工程款本来就分批结，按计划排好，哪期该到、到了没有，一目了然。
  • 每笔收款留痕：收款日期、金额、备注都记下来，客户说"我付过了"能当场核对。
  • 附件本地归档：合同、报价单、验收单扫描件存进项目，找资料不用翻文件柜和聊天记录。
  • 项目日志：谁在什么时候改了什么、沟通了什么，写下来才算数，扯皮时有依据。

5. 系统工具：账号权限、备份恢复、导入导出

给员工用也不用担心数据被乱改：支持多账号，管理员拥有完整权限，普通员工只能做被允许的操作。自带加密备份功能，定期把数据库打包备份，误删误改可以从备份恢复。

系统工具：账号权限管理、加密备份、导入导出
  • 多账号分权：老板看全部，员工只做业务，客户名单和金额不会被随手导走。
  • 加密备份：备份文件加密保存，拷贝给别人也打不开，防的是数据泄露不是防自己。
  • Excel 导入导出：客户清单、项目汇总随时导出，交给财务或自己留档都方便。

常见问题

Q：客户和项目数据会上传到服务器吗？

A：不会。全部数据保存在电脑本地的 SQLite 数据库文件里，软件运行不依赖联网，也不需要注册账号。

Q：换电脑了怎么办？

A：激活码绑定本机机器码，换电脑需要重新申请激活码。原有数据可以拷走数据库文件或从备份恢复，具体规则参考统一售后页面。

Q：电脑坏了，客户资料会不会全丢？

A：请养成定期备份的习惯。系统工具里有加密备份功能，把备份文件放到U盘或另一台电脑即可。数据在自己手里，风险也由自己控制，建议每周一次。

Q：以前客户资料都在 Excel 里，要重新录一遍吗？

A：不需要。支持按模板批量导入客户数据，导入后即可在系统里正常管理和关联项目。

Q：几个人可以同时用？

A：单机版装在一台电脑上，同一台电脑可以建多个账号区分权限。如果多人需要各自电脑同时协作，单机版并不合适，建议选择云端方案。

Q：能提醒我什么时候回访客户吗？

A：可以。给客户设置回访周期后，到期未跟进的客户会出现在首页提醒看板里，逾期会用颜色标出。

Q：试用版有哪些限制？

A：试用版可录入的客户数和项目数有限制，功能本身完整可用。购买激活后解除配额限制，数据继续沿用。
