功能详解：按房东一年到头的活儿排

下面都是软件里的真实界面（数据为演示数据）。录房 → 签租 → 每月出账 → 收租催欠 → 记维修和收支，就是完整的一年。

1. 首页仪表盘：今天该做什么，一屏说完

打开软件先看首页：上面是统计卡片（房源数、已出租、空置、本月应收），下面三类提醒——即将到期待收租、已欠费、待处理报修。该催谁、该修哪间，不用自己想。

首页仪表盘：统计卡片 + 三类待办提醒
  • 黄色是提醒，红色是欠费：还没到应收日但已进入提前提醒区间的，标黄；已经过了应收日还没交的，标红。
  • 提醒天数自己定：在系统设置里填 0~30 天，默认 7 天。习惯提前十天张罗的，就填 10。
  • 试用模式下首页会一直提示未激活，房源录到 3 套就停下——先试再决定。

2. 房源管理：几十间房，一台电脑管明白

按楼栋建房子：A 栋 201、B 栋 305，户型、面积、租金单价、押金、状态逐项填好。自建房常用的单间、一房一厅、铺面做成标签，筛的时候点一下就出来。

房源管理：状态、租金、押金一表看清，可切卡片/列表
新增房源：楼栋房号、户型面积、租金押金
  • 空置房一键筛：哪间到期没续、哪间刚退租，筛一下就知道，不用挨个翻。
  • Excel 批量导入导出：房子多的，在 Excel 里整理好一次导进来，比一间间点快得多。
  • 卡片视图适合看整体，列表视图适合改数据，两种视图随时切。

3. 租客与合同：押一付一写清楚，附件塞在同一个地方

一个租客一条记录：姓名、电话、身份证号、入住日期、到期日期、付款周期（月付 / 季付 / 半年付 / 年付）、押金，绑定到具体那间房。身份证照片和纸质合同也能直接传上来，跟记录挂在一起。

租客合同：租期、付款周期、押金与附件统一管理
新增合同：选房源、填租期，正反面身份证与合同都能传
  • 附件可多选上传：支持 jpg / png / pdf，一户能存正反面身份证和多份合同，单元格上有图标，点开就能查看，也能用系统默认程序打开。
  • 文件不入库：数据库只记文件路径，不把图片塞进数据库，软件不会越用越臃肿。
  • 合同到期提醒：快到期的人提前浮出来，续租、退租、调价都来得及安排。

4. 租金账单与欠费：每期自动出账，收了就点一下

每一期账单包含租金、水电、物业、其他扣费，系统算出本期应收。收到钱就标「已收」并填收款时间；没收到就一直在欠费列表里挂着，跑不掉。

租金账单：本期应收、已收未收、逾期一目了然
新增账单：租金 + 水电物业 + 其他扣费，自动合计
  • 欠费台账自动汇总：所有逾期账单归到一处，谁欠、欠几个月、欠多少，一列排开。
  • 历史收租可回查：按租客、房间、月份筛，租客说"我上个月交过了"，拉出来看时间就行。
  • 暂不接线上支付：这版只做记账，微信、支付宝怎么收还是你原来的方式，软件只负责记清楚。

5. 报修登记：谁报的、修没修、花了多少

租客发消息说水管漏了，就记一条报修：房号、内容、时间、状态（待处理 / 处理中 / 已完成）、维修费用。修完把费用填上，月底汇总时自动算进支出。

报修登记：状态流转 + 维修费用留痕
  • 普通用户也能报修：家人或代管的亲戚登录后可以直接登记，但不能删别人的记录。
  • 费用有去处：维修费用填了之后进收支台账，年底算净收益时不会漏掉这笔。

6. 收支台账：一个月到底落了多少

收入侧记租金、押金、其他收入，支出侧记维修材料、水电公摊、保洁、其他支出。月度汇总给出当月总收入、总支出、净收益，一张表说清这个月的账。

收支台账：收入支出分类记录，按月出净收益
  • 不追求财务软件那套：只有收支和月度汇总，没有复杂报表，够房东自己看明白就行。
  • 数据可导出：房源表、租客表、收租记录表都能导 Excel，给家里人看或存档都方便。

7. 账号与系统设置：谁能改、谁只能看

软件分两种账号。管理员是房东本人，什么都管；普通用户是家人或代管的亲戚，只能看基础信息、登记报修、看收租提醒，删房源、改租金、导出全部数据这些动作是锁住的。系统设置单独一页，只有管理员进得去。

账号管理：新增子账号、改密码、禁用
系统设置：租金提醒天数、备份恢复、授权信息、关于
  • 权限写在配置里：普通用户改不了提醒天数，也不会误删房源，家里老人帮忙收租也放心。
  • 密码本地加盐哈希：bcrypt 存储，软件里看不到明文。
  • 备份就一步：把本地数据库另存到 U 盘或另一块硬盘，换电脑恢复即可。

适合哪些人用

核心就一条：房子是自己的，数量在几十套以内，账想自己拿在手里。

城中村自建房房东

5~50 间房，租客流动快、付款周期不统一，最需要"到期提醒 + 欠费台账"这两样。

有多套房的小业主

家人 / 亲戚代管

房东常不在本地，让家里人帮忙收租、登记报修，用普通用户账号就够了，改不了关键数据。

常见问题

Q：房源、租客、身份证这些数据会上传吗？

A：不会。全部存在本机的 SQLite 数据库文件里，软件不联网也能完整使用。身份证和合同附件也只记录本地文件路径，不上传任何服务器。

Q：试用版有什么限制？

A：只限房源数——最多录 3 套。功能不删减，收租、欠费、报修、收支都能正常用，买断后不限房源数。

Q：换电脑了怎么办？

A：授权绑定机器码，换机需要重新签发授权串，走售后页面处理即可。换之前记得先在【系统设置】里做一次数据备份，到新电脑恢复。

Q：给家里人开的账号能看到什么？

A：普通用户只能看基础信息、登记报修、查看待收租提醒；删除房源、修改租金、新增账号、批量导出、修改系统配置都是禁止的。房东不在家也不怕数据被改乱。

Q：能在软件里直接微信收租吗？

A：不能，这一版不接线上支付和自动代扣。钱还是按你原来的方式收，软件负责记清楚谁交了、什么时候交的、谁还欠着。

Q：上传的身份证照片、合同会不会丢？

A：软件只记录文件路径，原文件要留在自己电脑上。文件被移动或删除时，打开会提示找不到。建议把附件统一放在一个固定文件夹，跟数据库一起备份。

Q：我完全不懂电脑，能学会吗？

A：左侧菜单八个入口，录房、签租、出账单的流程跟手写本子的顺序一致。正常半小时能上手。试用免费，学不会不花钱。
